# Ankicaster

- **show_banner** — the strip under Anki's toolbar. Set to false to remove it.
- **banner_hide_in_review** — hide that strip while a card is on screen. The Decks and overview screens still show it.
- **sync_saves** — keep the school in the Anki collection so another computer can open the same one. Leave this off if you only study on one machine.
- **min_answer_elapsed_ms** — a review faster than this earns nothing. 800 is the honest pace.
- **auto_open_on_startup** — open the academy when Anki starts.
